# Auralis – Android Application

Auralis is an Android mobile application developed
using Kotlin and Android Studio.

## Technologies Used
- Kotlin
- Android Studio
- Android SDK
- Gradle

## Features
- User login and sign-up screens
- User profile screen
- Tips section
- Android mobile interface

## Project Structure
- `app/src/main/java/` – Kotlin source code
- `app/src/main/res/` – Android resources
- `app/build.gradle.kts` – Gradle configuration

## Getting Started

1. Clone the repository:

   git clone https://github.com/MalshaDissanayake-2000/Auralis.git

2. Open the project in Android Studio.
3. Wait for Gradle synchronization.
4. Run the application on an emulator or Android device.
